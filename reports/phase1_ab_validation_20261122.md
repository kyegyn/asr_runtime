## 修正后的 VAD 指标

旧版的 `valid_speech_sec` 实际是首尾语音帧跨度，旧版 P50/P95 为 1,710/4,933ms；修改后的明确口径如下：

| 指标 | 修改后 P50/P95 |
|---|---:|
| 实际语音帧累计时长 | 1,664.0/4,294.4ms |
| 语音段时间跨度 | 1,712.0/4,931.2ms |
| ASR 实际输入时长 | 2,608.0/5,827.2ms |
| VAD 单帧平均耗时 | 0.397/0.398ms |
| 当前语音段 VAD 累计耗时 | 32.6/72.1ms |
| 静音收尾 | 672.0/672.0ms |

旧版 `vad_compute_ms` 的 P50/P95 为 42.4/81.0ms，但包含分段之间的无关静音，和新口径不能直接做性能比较。

## 队列与过载

修改后实时回放：

- 接受模型任务：50
- 丢弃模型任务：0
- 分支提交异常：0
- Worker 重启：0
- submission、ASR pending、SID pending、callback 最大深度均为 1

单元压力测试中，模型调度线程被人为阻塞并连续拒绝 100 次模型提交时，模拟麦克风采集丢帧为 0。该结果证明主音频消费路径不再同步等待模型提交，但不能替代真实声卡长时间压力测试。

## 结论与限制

1. 本测试集上没有出现 VAD 漏段、运行失败、超时或队列丢弃。
2. 规范化 ASR 准确率和 CER 未回退；ASR 与端到端 P95 略有改善。
3. SID P95 基本持平，P50 上升 13.7%；单次运行不足以认定稳定回退或改善，需要多轮重复测试。
4. 声纹 matched 比例提高，但数据只有一个 TTS 音色，不能证明真人声纹准确率改善。
5. 测试集没有真人超短指令和负样本，不能计算短指令漏检率或误触发率，也不支持调整 `min_speech_ms`、`min_segment_ms`。
6. 本报告不替代也不覆盖原 V2 性能报告；正式验收仍需多轮同条件基准、真人短指令集、环境负样本和真实麦克风长时间压力测试。
